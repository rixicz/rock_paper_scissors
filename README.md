# Rock, Paper, Scissors

A simple browser-based Rock, Paper, Scissors game where you play against the computer. The first player to win 5 rounds wins the game.

## Overview

This project is a lightweight JavaScript web app built with plain HTML, CSS, and JavaScript. It demonstrates basic DOM manipulation, event handling, and score tracking in a small interactive game.

## Key Features

- Play Rock, Paper, Scissors against a computer
- Track your score and the computer's score
- Display each round result in the UI
- End the game when one player reaches 5 wins
- Reset and start a new game with the click of a button


## Usage

1. Open this link: https://rixicz.github.io/rock_paper_scissors/
2. Click the New Game button to start a match.
3. Choose Rock, Paper, or Scissors.
4. The computer will make a random choice.
5. The result of the round will be displayed on the screen.
6. Continue playing until one player reaches 5 wins.

### Example

```text
Player chooses: Rock
Computer chooses: Scissors
Result: You won the round.
```
