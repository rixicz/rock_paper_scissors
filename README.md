# Rock, Paper, Scissors

A simple browser-based Rock, Paper, Scissors game where you play against the computer. The first player to win 5 rounds wins the game.

## Overview

This project is a lightweight JavaScript web app built with plain HTML, CSS, and JavaScript. It demonstrates basic DOM manipulation, event handling, and score tracking in a small interactive game.

## Key Features

- Play Rock, Paper, Scissors against a computer
- Track your score and the computer's score
- Display each round result in the UI
- End the game when one player reaches 5 wins
- Reset and start a new game with the click of a button

## Prerequisites

To run this project locally, you only need:

- A modern web browser such as Chrome, Edge, Firefox, or Safari
- A simple local web server (optional, but recommended)

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd rock_paper_scissors
   ```

2. Open the project folder in your preferred code editor.

3. Start a local server (optional but recommended):
   ```bash
   python -m http.server 8000
   ```

4. Open your browser and visit:
   ```text
   http://localhost:8000
   ```

If you prefer not to use a server, you can also go to https://rixicz.github.io/rock_paper_scissors/ or open the index.html file directly in your browser.

## Usage

1. Click the New Game button to start a match.
2. Choose Rock, Paper, or Scissors.
3. The computer will make a random choice.
4. The result of the round will be displayed on the screen.
5. Continue playing until one player reaches 5 wins.

### Example

```text
Player chooses: Rock
Computer chooses: Scissors
Result: You won the round.
```
